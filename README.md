# Rollvia

Modern, calm, and professional Windows desktop attendance management application.

## Overview
Rollvia is an offline-first Windows desktop attendance management system built with Electron, React, and TypeScript. It supports local Excel attendance matrix tracking, Google Sheets integration, student roster management, timetable scheduling, quick command attendance input, and multi-page PDF reporting.

## Getting Started

### Development
```bash
npm install
npm run dev:electron
```

### Production Build
```bash
npm run build
npm run electron:pack
npm run electron:dist
```
